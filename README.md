# Daily Earn Pro (डेली अर्न प्रो)

**Daily Earn Pro** एक आधुनिक, मोबाइल-फर्स्ट एंड्रॉइड-रेडी क्रिएटर और फ्रीलांस अर्निंग स्टूडियो है। इसे विशेष रूप से ऐसे उपयोगकर्ताओं के लिए डिज़ाइन किया गया है जो **बिना कंप्यूटर के सिर्फ अपने एंड्रॉइड स्मार्टफोन से** सोशल मीडिया पोस्टर्स, 16:9 यूट्यूब थंबनेल और वायरल कैप्शन्स बनाकर स्थानीय व ऑनलाइन क्लाइंट्स से वास्तविक कमाई करना चाहते हैं।

---

## 🌟 मुख्य विशेषताएं (Core Features)

1. **सोशल मीडिया पोस्टर मेकर (Social Media Poster Maker - 1:1 Square)**
   - 1080×1080 पिक्सल हाई-रेजोल्यूशन कैनवास।
   - बिजनेस सेल, दैनिक सुविचार, त्योहार, भर्ती, कैफे और जिम जैसे रेडीमेड प्रीसेट्स।
   - कलर ग्रेडिएंट्स, टेक्स्ट फॉन्ट साइज, अलाइनमेंट, फ्रेम्स और बॉर्डर्स।
   - सीधे मोबाइल में PNG डाउनलोड और व्हाट्सएप/इंस्टाग्राम पर डायरेक्ट शेयर।

2. **यूट्यूब थंबनेल मेकर (YouTube Thumbnail Maker - 16:9 HD)**
   - 1280×720 पिक्सल ओरिजिनल यूट्यूब थंबनेल साइज।
   - सीटीआर (Click-Through Rate) बूस्टर: बोल्ड आउटलाइन, नियॉन टेक्स्ट ग्लो और क्लिक-मैग्नेट स्टिकर्स (🔥, ▶️, 💰, ⭐, ⚠️)।
   - आकर्षक हाई-कंट्रास्ट बैकग्राउंड्स (Viral Fire, Cyber Neon, Finance Gold, Royal YouTube)।

3. **स्मार्ट कैप्शन व हैशटैग जनरेटर (Caption Generator)**
   - हिंदी और अंग्रेजी दोनों भाषाओं में उपलब्ध।
   - बिजनेस, मोटिवेशन, फ्रीलांसिंग, त्योहार, और यूट्यूब वीडियो के लिए सत्यापित ऑफलाइन टेम्पलेट्स।
   - 1-क्लिक कॉपी टू क्लिपबोर्ड और शेयरिंग।
   - सुरक्षित बैकएंड के माध्यम से वैकल्पिक Gemini 3.8 Flash AI जनरेशन।

4. **मेरी फाइलें (My Work Vault)**
   - आपके द्वारा बनाए गए सभी पोस्टर्स, थंबनेल्स और कैप्शन्स फोन में सुरक्षित सेव रहते हैं।
   - 1-क्लिक में किसी भी पुराने प्रोजेक्ट को दोबारा खोलें और एडिट (Reopen & Edit) करें।
   - स्टोरेज कोटा मैनेजमेंट और डिलीट कन्फर्मेशन।

5. **प्रमाणित कमाई गाइड (Legitimate Earning Roadmap)**
   - स्थानीय दुकानों (कपड़े, सैलून, जिम, कैफे) को पोस्टर बेचकर ₹15,000 - ₹35,000/माह कमाने के तरीके।
   - यूट्यूबर्स को थंबनेल सर्विस पिच करने के लिए कॉपी करने योग्य WhatsApp व Email संदेश (Pitch Templates)।
   - इंटरएक्टिव मासिक कमाई कैलकुलेटर।
   - **स्पष्ट नियम:** कोई फर्जी क्लिक-कमाई या सट्टा नहीं, यह असली हुनर और क्लाइंट वर्क से कमाई सिखाता है।

6. **गूगल एडमोब (Google AdMob) तैयारी**
   - सुरक्षित एडमोब प्लेसमेंट एरिया और एंड्रॉइड इंटीग्रेशन गाइड।
   - पॉलिसी के अनुसार जब तक अपनी एड आईडी कॉन्फ़िगर नहीं की जाती, तब तक सभी विज्ञापन बंद रहते हैं।

7. **नेटिव ऐप शेयर इंटीग्रेशन (Native App Share Feature)**
   - होम डैशबोर्ड पर 1-टैप शेयर बटन।
   - Android APK में Capacitor Share Plugin के जरिए नेटिव शेयर मेनू (WhatsApp, Telegram, Gmail, Bluetooth आदि) खुलता है।
   - मोबाइल वेब में Web Share API और डेस्कटॉप पर ऑटोमेटिक कॉपी लिंक फॉलबैक।
   - असली Play Store लिंक कॉन्फ़िगर करने के लिए `src/services/shareService.ts` में स्पष्ट जगह दी गई है (`OFFICIAL_PLAY_STORE_URL`)। कोई फर्जी लिंक नहीं बनाया गया है।

## 📱 सिर्फ मोबाइल से APK कैसे बनाएं (Build Android APK using only Phone)

आपको किसी लैपटॉप या कंप्यूटर की जरूरत नहीं है। इस रिपॉजिटरी में GitHub Actions का ऑटोमेटेड वर्कफ्लो (`.github/workflows/build-android.yml`) पहले से शामिल है।

### स्टेप 1: कोड को GitHub पर डालें
1. अपने मोबाइल ब्राउज़र (जैसे Chrome) में [github.com](https://github.com) खोलें।
2. **New Repository** बनाएं (नाम: `daily-earn-pro`)।
3. इस प्रोजेक्ट की सभी फाइलें अपलोड करें (या `git push origin main` करें)।

### स्टेप 2: GitHub Actions में APK बिल्ड शुरू करें
1. अपने फोन में GitHub रिपोजिटरी के पेज पर ऊपर **"Actions"** टैब पर टैप करें।
2. बायीं तरफ **"Build Android Debug APK"** वर्कफ्लो चुनें।
3. **"Run workflow"** बटन पर क्लिक करें और **Branch: main** चुनकर नीले बटन पर टैप करें।

### स्टेप 3: APK डाउनलोड और इंस्टॉल करें
1. GitHub क्लाउड में लगभग 2 से 3 मिनट में आपकी APK फाइल तैयार हो जाएगी और ग्रीन टिक (✅) आ जाएगा।
2. उस सफल रन (Run) पर टैप करें और नीचे **"Artifacts"** सेक्शन में जाएं।
3. **`DailyEarnPro-v1.0.0-Debug-APK`** पर टैप करें।
4. आपके फोन में zip फाइल डाउनलोड हो जाएगी। उसे अनजिप करें और `.apk` फाइल पर टैप करके इंस्टॉल कर लें!

अगर आपके पास कंप्यूटर या Android Studio है, तो आप इन कमांड्स का उपयोग कर सकते हैं:

## 💰 भविष्य में गूगल एडमोब (AdMob) कैसे चालू करें

जब आप ऐप को Google Play Store पर डालने के लिए तैयार हों:
1. [Google AdMob](https://admob.google.com) पर अकाउंट बनाएं और एक नया Android App रजिस्टर करें।
2. आपको एक **App ID** मिलेगा (उदा. `ca-app-pub-XXXXXXXXXXXXXXXX~YYYYYYYYYY`)।
3. Capacitor AdMob प्लगइन इंस्टॉल करें:
   ```bash
   npm install @capacitor-community/admob
   npx cap sync android
   ```
4. `android/app/src/main/AndroidManifest.xml` में `<application>` टैग के अंदर अपनी App ID जोड़ें:
   ```xml
   <meta-data
       android:name="com.google.android.gms.ads.APPLICATION_ID"
       android:value="ca-app-pub-XXXXXXXXXXXXXXXX~YYYYYYYYYY"/>
   ```
5. Google की UMP (User Messaging Platform) SDK के तहत प्राइवेसी कंसेंट का पालन करें।

## 🛠️ सामान्य समस्याएं और समाधान (Troubleshooting)

- **समस्या: GitHub Actions में `package-lock.json` या dependency conflict की वजह से npm ci फेल हो रहा था?**
  - **समाधान:** `esbuild` और `vite` के पीयर-डिपेंडेंसी कनफ्लिक्ट को ठीक कर दिया गया है और `package-lock.json` को कंसिस्टेंट वर्शन के साथ जेनरेट कर दिया गया है।
- **समस्या: GitHub Actions में Gradle build fail हो रहा है?**
  - **समाधान:** सुनिश्चित करें कि `.github/workflows/build-android.yml` में `npx cap add android` और `chmod +x android/gradlew` शामिल है। यह वर्कफ्लो में पहले से कॉन्फ़िगर है।
- **समस्या: फोटो डाउनलोड होने के बाद गैलरी में नहीं दिख रही?**
  - **समाधान:** अपने फोन के "Downloads" या "Files" ऐप में जाएं। वहां `daily-earn-poster-*.png` नाम से फाइल मिल जाएगी।
- **समस्या: AI कैप्शन काम नहीं कर रहा?**
  - **समाधान:** AI के लिए सर्वर पर `GEMINI_API_KEY` होना चाहिए। यदि इंटरनेट नहीं है या की (Key) मौजूद नहीं है, तो ऐप स्वचालित रूप से बिना रुके हाई-क्वालिटी **ऑफलाइन टेम्पलेट्स** का उपयोग करता है।
